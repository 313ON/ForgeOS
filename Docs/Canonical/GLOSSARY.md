# Glossary

## Bootstrap

Application initialization process.

---

## Runtime

Core execution engine.

---

## Registry

Service registration container.

---

## Plugin

Loadable ForgeOS extension.

---

## Canonical

Official project definition.

---

## Lifecycle

Startup and shutdown process.

---

## Service

Core reusable functionality.

---

## Workspace

User operating environment.

---

## Architecture Gap

A required capability for which ForgeOS has no verified current interface or
implementation. Gaps must be documented rather than replaced with invented services.

---

## Knowledge Layer

The bounded context that owns durable assets, people, assignments, diagnostics,
monitoring definitions, and operational records.

---

## Execution Layer

The AgentOS bounded context that owns agent runs, tool calls, approvals, cancellation,
token usage, and execution cost.

---

## NOC

Network Operations Center. The high-density ForgeOS workspace for operational health,
topology, exceptions, and recent telemetry.
